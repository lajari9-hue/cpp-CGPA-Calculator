# 🎓 C++ CGPA Calculator

A simple **CGPA Calculator** developed using C++. The program calculates the semester GPA/CGPA based on the grade points and credit hours of each course.

 🚀 Features

- Accepts the number of courses
- Accepts grade points for each course
- Accepts credit hours
- Calculates total credits
- Calculates total grade points
- Calculates GPA
- Displays the overall CGPA
- Validates grade points and credit hours

 🛠️ Technologies Used

- C++
- Loops
- Conditional Statements
- Functions/Variables
- Mathematical Calculations
- Input/Output

 🧮 Formula

The program calculates grade points using:


Grade Points = Grade × Credit Hours

GPA is calculated using:
GPA = Total Grade Points / Total Credits


For a single semester:

CGPA = GPA

## ⚙️ How to Run

Compile the program:

bash

Run on Windows:

bash
.\cgpa.exe


Run on Linux/macOS:

bash
./cgpa
